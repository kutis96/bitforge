    bitforge

    bitforge is a bitmap font editor for fixed-size, zero-spacing, non-proportional monospaced fonts — 256 glyphs per face, cell size of your choosing (default 8×16).

    Edit a 256-glyph bitmap font of any size (default 8×16), preview it with artificial bold and a cheap slant, track per-glyph status (unfinished / wip / done), run QA checks, and export a PNG atlas, BDF, a TrueType (.ttf) font, or a Verilog $readmemb ROM — or toggle on dogfooding and read the app's own UI in the face you're drawing.

    Designed by spacecat · Coded by Qwen 3.8 (Bionic harness) · vanilla JS, zero dependencies, runs straight from file://
